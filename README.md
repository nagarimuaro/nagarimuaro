<h2 align="center">🏘️ SINTA — Sistem Informasi Nagari Terpadu</h2>

<p align="center">
  Platform digital terintegrasi untuk modernisasi pemerintahan nagari,
  pengelolaan data masyarakat, dan pelayanan publik.
</p>

---

### 🚀 Core Modules

- **Kependudukan** — Data warga, keluarga, dan indikator sosial ekonomi.
- **Persuratan Digital** — Administrasi dan pembuatan surat otomatis.
- **Pelayanan Publik** — Layanan masyarakat dan pengaduan.
- **Keuangan & Aset** — Pengelolaan keuangan dan inventaris nagari.
- **Infrastruktur** — Monitoring pembangunan dan aset.
- **UMKM & BUMNAG** — Direktori dan pengelolaan usaha nagari.
- **WhatsApp AI** — Integrasi layanan masyarakat melalui WhatsApp.

### 🛠️ Technology Stack

| Component | Technology |
|---|---|
| Backend | Laravel 12 |
| Database | PostgreSQL |
| Authentication | Laravel Sanctum |
| Architecture | Multi-Tenant |
| AI Integration | OpenAI API |
| Document Generation | PhpWord, DomPDF, TCPDF |
| Media Management | Spatie Media Library |

### 🏗️ Platform Architecture

SINTA mengintegrasikan berbagai antarmuka:
- Public Website
- Admin Dashboard
- Wali Nagari Dashboard
- Kader Mobile Application
- Jorong Management
- Anjungan Nagari Mandiri (ANM)
